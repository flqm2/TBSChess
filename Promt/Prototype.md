# 이동·충돌·턴 프로토타입

## 승인 범위

2026-11-07 사용자 지시와 배치 수 확인 답변에 따라 정식 게임 PRD와 별도로 진행한다. 진영당 2기, 총 4기를 동시에 배치하고 이동·기물 충돌·턴 진행을 확인한다. 보드는 배경 이미지 대신 선으로 그린 8×4 격자다. Resource의 원본 이미지 4개를 모두 사용한다. 코드는 기존 `Script/` 폴더에서 기능별 클래스로 나누고 `Script/main.py`에서 실행한다.

## 이번 구현의 동작

- 청팀: 슬레이어(상하좌우), 암살자(전 방향). 홍팀: 메이지(대각선), 카드술사(전 방향).
- 각 기물은 자신의 방향으로 인접 1칸씩 이동한다. 시작 위치는 각자 진영에 있지만 프로토타입에서는 8×4 전체를 이동하여 적·아군 충돌을 확인한다. 중앙선은 구역 표시이며 이동을 막지 않는다.
- 어느 진영이든 기물이 있는 칸은 진입할 수 없다. 겹침·밀기·뛰어넘기·처치는 발생하지 않는다.
- 차례는 청1 → 홍1 → 청2 → 홍2 순서다. 네 차례가 끝나면 라운드가 증가한다.
- 현재 차례의 기물만 이동한다. 성공한 이동은 턴을 넘긴다. 잘못된 방향·보드 밖·점유 칸 클릭은 위치와 턴을 유지한다.
- Space는 이동할 수 없는 경우에도 진행을 확인하기 위한 턴 넘김이다. 정식 게임의 대기 규칙 확정과는 별개다.
- 이동 가능 칸·현재 차례·팀·라운드·실패 사유·최근 행동 4개를 표시한다. 양쪽 기물 모두 사용자가 조작한다.
- 전투 AI·주사위·공격·스킬·영웅화·최종전은 이번 범위에 포함하지 않는다.

## 실행과 조작

기존 Python 3.11에 설치된 pico2d 1.5.1을 사용한다. `.venv` 생성·활성화나 라이브러리 재설치는 필요 없다. 저장소 루트에서 실행한다.

```powershell
python Script/main.py
```

어느 작업 디렉터리에서 실행해도 리소스는 소스 파일의 절대 위치를 기준으로 읽는다. 한국어 표시는 Windows의 맑은 고딕을 사용한다.

- 왼쪽 클릭: 현재 차례 기물의 목적지 선택.
- Space: 현재 차례 넘김.
- 화면의 ‘검증용 턴 넘김’ 버튼: Space와 동일.
- Esc 또는 창 닫기: 종료.

## 파일 역할

| 파일 | 담당 |
| --- | --- |
| `Script/main.py` | pico2d 실행·이벤트 루프·종료 |
| `Script/battle_view.py` | 선 격자·원본 이미지·상태 표시·마우스 좌표 변환 |
| `Script/board.py` | 8×4 좌표·점유 조회·초기 배치 유효성 |
| `Script/piece.py` | 기물 상태와 직업 이동 방향 |
| `Script/movement.py` | 직업별 한 칸 이동·외곽·점유 충돌, 미리보기와 실행의 공통 판정 |
| `Script/turn_manager.py` | 교대 순서와 라운드 |
| `Script/prototype.py` | 4기 초기 배치 및 이동/턴 연결 |

## 검증과 저장 단위

1. **프로토타입: 기물과 8×4 보드 클래스 제작** — 기물·직업 방향·좌표·점유와 배치 유효성.
2. **프로토타입: 이동 충돌 처리와 교대 턴 진행 구현** — 공통 이동 판정·4기 배치·고정 순서·라운드.
3. **프로토타입: pico2d 격자 화면과 조작 연결** — 실행 진입점·뷰·원본 이미지 4개·실행 안내.

파일을 남기지 않는 Python 표준입력 검증으로 이동·충돌·턴·라운드·미리보기 일치에 대한 211개 조건을 확인했다. 각 직업을 보드 전체 위치로 옮겨 미리보기와 실제 유효 목적지를 대조했다. 초기 배치의 중복 식별자·겹침·보드 밖 위치도 별도로 확인했다.

실제 SDL 창에서 이미지·한국어 글꼴 렌더링, 32칸 화면 좌표 변환, 왼쪽/오른쪽 클릭 구분, 잘못된 이동, Space·버튼 턴 넘김, Esc·창 닫기 처리를 확인했다. 저장소 밖 작업 폴더에서도 원본 리소스를 불러오는 것을 확인했다. 화면 캡처는 직접 검토한 뒤 삭제했으며 검증 스크립트·검토 폴더·가상환경·바이트코드 캐시를 남기지 않는다.
