# 이동·충돌·턴 프로토타입

## 승인 범위

2026-11-07 사용자 지시에 따라 정식 게임 PRD와 별도로 진행한다. 진영당 2기, 총 4기를 배치하고 이동·기물 충돌·턴 진행을 확인한다. 보드는 배경 이미지 대신 선으로 그린 8×4 격자다. Resource의 원본 이미지 4개를 모두 사용한다.

## 이번 구현의 동작

- 청팀: 슬레이어(상하좌우), 암살자(전 방향). 홍팀: 메이지(대각선), 카드술사(전 방향).
- 각 기물은 자신의 방향으로 인접 1칸씩 이동한다. 시작 위치는 각자 진영에 있지만 프로토타입에서는 8×4 전체를 이동하여 적·아군 충돌을 확인한다. 중앙선은 구역 표시이며 이동을 막지 않는다.
- 어느 진영이든 기물이 있는 칸은 진입할 수 없다. 겹침·밀기·뛰어넘기·처치는 발생하지 않는다.
- 차례는 청1 → 홍1 → 청2 → 홍2 순서다. 네 차례가 끝나면 라운드가 증가한다.
- 현재 차례의 기물만 이동한다. 성공한 이동은 턴을 넘긴다. 잘못된 방향·보드 밖·점유 칸 클릭은 위치와 턴을 유지한다.
- Space는 이동할 수 없는 경우에도 진행을 확인하기 위한 턴 넘김이다. 정식 게임의 대기 규칙 확정과는 별개다.
- 이동 가능 칸·현재 차례·팀·라운드·실패 사유를 표시한다. 양쪽 기물 모두 사용자가 조작한다.
- 전투 AI·주사위·공격·스킬·영웅화·최종전은 이번 범위에 포함하지 않는다.

## 실행과 조작

설치된 pico2d를 사용할 수 있는 Python 환경에서 저장소 루트를 기준으로 실행한다.

```powershell
python Script/main.py
```

어느 작업 디렉터리에서 실행해도 리소스는 소스 파일의 절대 위치를 기준으로 읽는다. 한국어 표시는 Windows의 맑은 고딕을 사용한다.

- 왼쪽 클릭: 현재 차례 기물의 목적지 선택.
- Space: 현재 차례 넘김.
- Esc 또는 창 닫기: 종료.

## 파일 역할

| 파일 | 담당 |
| --- | --- |
| `Script/main.py` | pico2d 실행·이벤트 루프·종료 |
| `Script/battle_view.py` | 선 격자·원본 이미지·상태 표시·마우스 좌표 변환 |
| `Script/board.py` | 보드 경계·점유·유효 목적지 |
| `Script/piece.py` | 기물 상태와 직업 이동 방향 |
| `Script/turn_manager.py` | 교대 순서와 라운드 |
| `Script/prototype.py` | 4기 초기 배치 및 이동/턴 연결 |
| `tests/test_prototype.py` | 화면 없이 이동·충돌·턴 규칙 검증 |

## 검증과 저장 단위

1. **프로토타입: 격자와 기물 이동·충돌 규칙 구현** — 보드·기물·턴·프로토타입 상태 및 규칙 검증.
2. **프로토타입: pico2d 화면과 입력 연결** — 실행 진입점·뷰·4개 리소스 이미지·의존성 목록.
3. **문서: 프로토타입 범위와 실행 방법 정리** — 본 문서·PRD 진행 기록·작업 원칙 연결.

검증 명령: `python -m unittest discover -s tests -v`.

실행에 사용하는 Python에 pico2d가 이미 있다면 재설치하지 않는다. 현재 에이전트의 기본 Python 3.11에서는 모듈을 찾지 못했으나, 사용자는 설치되어 있음을 확인했다. 그래픽 실행 검증은 설치된 Python 환경을 찾은 뒤 수행한다. 규칙 테스트 통과를 실제 화면 확인 완료와 혼동하지 않는다.
